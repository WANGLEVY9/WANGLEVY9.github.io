02 / Research

Evidence
before claims.

Current record Three submitted manuscripts, each separating what was measured from what can be claimed. Statuses remain open until a formal decision or camera-ready record exists.

The throughline is behavioral evidence: completion is not correctness, a terminal failure is not necessarily the root cause, and automated coverage is not the same as trustworthy judgment.

Submitted manuscript Research affiliation
A01
FSE 2027 Research Track · Submitted First author

Computer-Use Agents for Web UI Testing: What Do We Need to Know?

Nanyang Technological University · Cybersecurity Lab

A controlled empirical framework comparing visual agents, structure-aware agents, and scripted tests for web UI testing. The study separates task completion from check execution and judgment correctness, then examines preparation cost, repeatability, and complementary coverage under equal execution budgets.

  • Controlled comparison
  • Agent evaluation
  • Coverage
Unit of analysis
Web UI testing behavior
Core distinction
Completion vs. correct checking
Evaluation lens
Cost, repeatability, coverage

Submitted status is not presented as publication or acceptance.

A02
TOSEM · Submitted 2026 First author · 2-person team

SOCRATES: Cost-Aware Human–AI Root Localization for Failed GUI Agent Executions

Nanjing University · Intelligent Software Engineering Lab

A human–AI method for finding the earliest faulty action in long GUI trajectories. SOCRATES jointly models action-level root-cause probability and the cost of human inspection, using interval dynamic programming to choose what to check next and shrink the candidate range without exhausting the review budget.

  • Root-cause analysis
  • Human–AI collaboration
  • Interval DP
Failure object
Earliest faulty GUI action
Decision model
Risk × inspection cost
Review policy
Interval DP over candidates

The method targets diagnosis under a bounded human-review budget.

A03
TOSEM · Submitted 2026 First author · listed second of 3

Unmanned Autonomous Systems Testing in the Era of Large Models: State of the Art, Challenges, and Opportunities

Nanjing University · State Key Laboratory for Novel Software Technology

A systematic survey spanning autonomous driving, UAVs, and robotics. The work organizes methods across testing stages, model techniques, and test granularity, then compares technical transfer and limits in scenario generation, test oracles, and result analysis.

  • Systematic survey
  • Autonomous systems
  • Test oracles
Scope
Driving · UAV · robotics
Organizing axes
Stage · technique · granularity
Analysis focus
Oracle and transfer limits

The survey maps the field without treating model capability as test adequacy.
