Profile

Research profile · Updated October 2026

Making AI-driven software testable, traceable, and accountable.

I am a final-year Software Engineering undergraduate at Nanjing University, working where software testing, GUI agents, and trustworthy AI meet.

My work asks a practical question: once an AI system acts, how do we know whether it acted correctly, where it first went wrong, and when a human should step in? I study controlled agent evaluation, root-cause localization for failed GUI trajectories, and human-in-the-loop inspection under limited budgets. I collaborate with labs at Nanjing University and Nanyang Technological University, and build production systems at Tencent's Weixin Group.

Research Experience

Three submitted manuscripts on how AI-driven software is tested, diagnosed, and made more dependable.

A
FSE 2027 Research Track · Submitted First author

Computer-Use Agents for Web UI Testing: What Do We Need to Know?

Nanyang Technological University · Cybersecurity Lab

A controlled empirical framework that compares visual agents, structure-aware agents, and scripted tests for web UI testing. The study separates task completion from check execution and judgment correctness, then examines preparation cost, repeatability, and complementary coverage under equal execution budgets.

  • Controlled comparison
  • Agent evaluation
  • Coverage
B
TOSEM · Submitted 2026 First author · 2-person team

SOCRATES: Cost-Aware Human–AI Root Localization for Failed GUI Agent Executions

Nanjing University · Intelligent Software Engineering Lab

A human–AI method for finding the earliest faulty action in long GUI trajectories. SOCRATES jointly models action-level root-cause probability and the cost of human inspection, using interval dynamic programming to choose what to check next and shrink the candidate range without exhausting the review budget.

  • Root-cause analysis
  • Human–AI collaboration
  • Interval DP
C
TOSEM · Submitted 2026 First author · listed second of 3

Unmanned Autonomous Systems Testing in the Era of Large Models: State of the Art, Challenges, and Opportunities

Nanjing University · State Key Laboratory for Novel Software Technology

A systematic survey spanning autonomous driving, UAVs, and robotics. The work organizes methods across testing stages, model techniques, and test granularity, then compares technical transfer and limits in scenario generation, test oracles, and result analysis.

  • Systematic survey
  • Autonomous systems
  • Test oracles
